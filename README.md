# 이음턱편한치과 홈페이지

정적 HTML 홈페이지입니다. 서버나 빌드 과정 없이 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 파일 구조

```
index.html      메인 페이지 (소개, 진료안내, 칼럼, 오시는길)
tmj.html        턱관절 클리닉 페이지 (증상, 자가진단, 치료법, FAQ)
css/style.css   공통 스타일 (색상·폰트는 맨 위 :root 변수만 수정)
```

## 채워야 할 정보 (검색: `[` 로 찾기)

- 병원 주소, 대중교통 안내 (`index.html` 오시는길, 푸터)
- 전화번호: `00-0000-0000` 을 전체 파일에서 실제 번호로 일괄 치환
- 진료시간 (현재 예시값)
- 사업자등록번호
- 병원 사진: `images/` 폴더에 아래 파일명으로 저장하면 자동으로 표시됩니다
  - `images/hero.jpg` — 메인 상단 배경 (치과 내부 넓은 사진 추천)
  - `images/doctor.jpg` — 병원 소개 옆 진료 사진
  - `images/feature-diagnosis.jpg` — 정밀 진단 (CT 장비 등)
  - `images/feature-treatment.jpg` — 진료 모습
  - `images/feature-counsel.jpg` — 상담실
  - `images/gallery-1.jpg` ~ `gallery-6.jpg` — 병원 둘러보기 갤러리
  - `images/logo.png` — 로고 원본 (현재는 SVG 재현본 사용 중)
  - 사진이 없으면 해당 자리는 연한 그라데이션으로 표시됩니다 (깨지지 않음)
- 건강 칼럼 카드 3개 → 실제 블로그 글 제목·링크로 교체
- 네이버 지도 퍼가기 코드 (오시는길 박스 안)

## 배포 방법 (무료)

1. **Netlify Drop (가장 쉬움)**: https://app.netlify.com/drop 접속 → 이 폴더를 통째로 드래그 → 즉시 URL 생성. 이후 도메인(예: eumtmj.co.kr) 구입해서 연결 가능.
2. **GitHub Pages**: GitHub 저장소에 올리고 Settings → Pages 활성화.

## AI 도구 역할 분담 (토큰 절약 전략)

**Claude Pro (이 프로젝트)** — 큰 작업만:
- 페이지 구조 변경, 새 페이지/섹션 추가
- 디자인 전면 수정, 반응형 문제 해결
- 복잡한 기능 추가 (예약 폼, 지도 연동 등)

**LM Studio (맥 로컬, 무료·무제한)** — 단순 반복 작업:
- 전화번호·주소·진료시간 등 텍스트 교체
- 블로그 카드 제목/링크 교체
- 문구 다듬기, 오타 수정
- 추천 모델: Qwen2.5-Coder 14B 또는 EXAONE 3.5 (한국어 강함)
- 사용법: 수정할 HTML 부분을 복사해 붙여넣고 "이 부분에서 전화번호를 02-123-4567로 바꿔줘"처럼 요청 → 결과를 파일에 다시 붙여넣기

**ChatGPT Plus** — 콘텐츠 작성:
- 블로그 글 초안, 칼럼 요약문
- SEO용 메타 설명 문구
- 이미지 생성 (DALL-E로 배너/일러스트)

이 순서로 쓰면 Claude 토큰은 구조적인 작업에만 아껴 쓸 수 있습니다.
